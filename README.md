## 📌 About

A clean, responsive **web development quiz app** built with vanilla HTML, CSS, and JavaScript.
Test your knowledge across HTML, CSS, JavaScript, DOM, and web fundamentals — with a live countdown timer, instant feedback, and a final score summary.

> Built to strengthen JavaScript logic, DOM manipulation, event handling, timers, and responsive frontend development.

## ✨ Features

| Feature | Description |
|---------|-------------|
| ⏱ **15-Second Timer** | Countdown per question — turns red when ≤ 5 seconds remain |
| 📊 **Live Score** | +10 points per correct answer, updates in real time |
| 🔀 **Randomised Questions** | Questions shuffle on every play — no two games alike |
| ✅ **Correct Feedback** | Right answer highlighted in green instantly |
| ❌ **Wrong Feedback** | Wrong answer shown in red, correct answer revealed |
| ⏰ **Time's Up Detection** | Auto-skips unanswered questions and shows the answer |
| 📈 **Result Summary** | Final score, accuracy %, correct / wrong / skipped count |
| 🏆 **Performance Rating** | 5-tier rating from Outstanding to Don't Give Up! |
| 📱 **Fully Responsive** | Works on desktop and mobile |

## ⚙️ How It Works

```
1. User lands on Start Screen
         ↓
2. Clicks "Start Quiz"
         ↓
3. 10 random questions load one by one
         ↓
4. Each question has a 15-second timer
         ↓
5. User picks an answer → instant feedback shown
         ↓
6. Score updates (+10 if correct)
         ↓
7. After 10 questions → Result Screen
         ↓
8. Shows score, accuracy %, performance rating
```
